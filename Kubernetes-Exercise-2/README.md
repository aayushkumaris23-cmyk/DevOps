# Kubernetes Exercise 2: Minikube, kubectl and Flask

## Objective
Deploy and access a Flask application running in a local Kubernetes cluster using Minikube.

## Business Scenario
Simulate a web application deployed on Kubernetes and make it accessible through a Kubernetes Service.

## Tools Used
- Docker Desktop
- Minikube
- kubectl
- Kubernetes
- Python Flask

## Implementation
1. Started the Minikube cluster.
2. Deployed the Flask application.
3. Configured the Kubernetes Service.
4. Verified the Pod and Service status.
5. Accessed the application using the Minikube service URL.
